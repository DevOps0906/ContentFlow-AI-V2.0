# 네이버 블로그 홈판 포스팅 규칙

버전: v0.1 / 작성일: 2026-11-16 · 상위: [CONTENT_TEMPLATES.md](CONTENT_TEMPLATES.md)(네이버 검색형·홈판형 프로필, T06) · 제품 기획: [NAVER_HOMEFEED.md](../01-planning/NAVER_HOMEFEED.md)

이 파일은 글을 만들 때 작성자와 AI가 따를 **규칙집**이다. 기획서의 모듈(H1~H5)을 실제 글쓰기에 적용하는 기준이며, 점검 항목은 경고로 쓰고 발행을 막지 않는다.

근거 등급
- **[공식]** 네이버 발표로 확인
- **[자료]** 강의·뉴스레터·블로그 등 2차 자료의 주장 (검증 안 됨)
- **[노트]** 특강 노트의 제목만 확인 (세부 미확인)
- **[규칙]** 사용자가 직접 정한 규칙
- **[제안]** 이 문서의 설계 판단

> 주의: 네이버는 홈판 알고리즘을 공개하지 않는다. 이 규칙은 "노출 보장"이 아니라 "반응과 전환을 높이기 위한 작성 기준"이다. 글에서도 노출을 보장하는 표현을 쓰지 않는다.

## 1. 글 목적 3종 (글마다 반드시 하나 지정)

| 목적 | 노리는 지면 | 독자 | 제목 공식 | 본문 중심 |
|---|---|---|---|---|
| 발견글 | 홈판·추천 | 구경하러 온 사람 | F2 (후킹형) | 경험·결과·호기심 |
| 문제해결글 | 검색 | 필요해서 찾는 사람 | F1 (검색형) | 질문에 대한 구체적 답 |
| 전환글 | 검색 + 상품 | 구매 직전 | F1 + 결과·절차 | 절차·비용·CTA |

- 초기 권장 비율: 발견 5 : 문제해결 3 : 전환 2 [제안]. 성과 기록을 보고 조정한다.
- 홈판 유입자는 구경형, 검색 유입자는 구매 직전형이라는 구분은 자료 주장이다 [자료].
- 수익 연결은 전환글에서 한다. 발견글에는 상품 광고를 넣지 않는다 [제안].

## 2. 키워드 규칙

1. 글 하나당 **키워드 세트**를 먼저 만든다: 메인 키워드 1개 + 세부 키워드 3개 이상 + 서브 키워드.
2. 인기 키워드 1개만으로 글을 쓰지 않는다 [노트].
3. **세부 키워드**는 검색 의도를 좁히는 말이다: 대상(누가), 상황(언제), 도구(무엇으로), 문제(무엇이 막혔나).
4. 서브 키워드는 본문에서 자연스럽게 쓴다. 누락하면 조회수에 불리하다는 특강 메모가 있다 [노트].
5. 후보 수집: 네이버 자동완성, 데이터랩, 독자 질문, Creator Advisor의 유입 키워드. 연관검색어 서비스는 2026년 4월 30일 종료되었다 [자료].
6. 키워드 나열 금지: 본문과 제목 모두 읽히는 문장으로 쓴다.

> 확인 필요: "세부 키워드 3개 이상" 규칙이 제목에 적용되는지 본문에 적용되는지는 특강 슬라이드를 확인해야 한다. 아래 제목 규칙은 [규칙]에 따라 "제목에 세부 키워드 최소 1개"로 시작하고, 확인 후 조정한다.

## 3. 제목 규칙 (핵심)

### 3.1 필수 규칙 [규칙]
**제목에는 메인 키워드와 세부 키워드를 모두 사용한다.** 검색용·홈판용 모두 적용한다.

- 메인 키워드: 정확히 1개 포함.
- 세부 키워드: 최소 1개 포함. 길이가 허용되면 2개(최대 3개)까지.
- 메인 키워드가 빠진 제목, 세부 키워드가 빠진 제목은 불합격이다.

### 3.2 형식 규칙 [제안]
1. 메인 키워드와 세부 키워드 1개는 제목 **앞쪽**에 둔다. 모바일에서 긴 제목은 중간에서 잘릴 수 있고, 한 자료는 약 27자를 넘으면 말줄임이 된다고 안내한다 [자료, 2023]. 잘려도 핵심이 보이게 한다.
2. 같은 키워드를 제목에서 두 번 이상 반복하지 않는다 [자료].
3. 후킹 요소를 하나 더한다: 숫자, 반전, 결과, 경험 중 택1. 홈판용(발견글)은 필수, 검색용은 선택 [자료].
4. 키워드를 단어 나열로 붙이지 않고, 하나의 읽히는 문장으로 만든다.
5. 본문이 제목의 약속을 지켜야 한다. 과장·낚시 표현은 금지한다.
6. 썸네일 문구와 제목이 같은 말을 반복하지 않는다 [자료].

### 3.3 제목 공식

| 코드 | 용도 | 구조 |
|---|---|---|
| F1 | 문제해결글·전환글 | [메인] + [세부1] + [세부2] + [정보 유형: 방법·순서·비교·후기] |
| F2 | 발견글 | [메인] + [세부1] + [후킹: 숫자·반전·결과] + [세부2] |

### 3.4 형식 예시 (가상 예시이며 실제 결과가 아님. 본인 경험으로 바꿔서 쓴다)

| 공식 | 메인 | 세부 | 제목 예시 |
|---|---|---|---|
| F1 | 바이브코딩 | 앱 출시, 구글플레이 | 바이브코딩 앱 출시, 구글플레이 등록 순서 정리 |
| F1 | 1인 출판사 | ISBN, 전자책 | 1인 출판사 ISBN 발급부터 전자책 등록까지 순서 |
| F2 | AI 자동화 | n8n, 블로그 초안 | AI 자동화 n8n으로 블로그 초안 만들었더니 생긴 일 |
| F2 | 바이브코딩 | 첫 앱, 비용 | 바이브코딩 첫 앱 만들 때 의외로 돈이 들었던 곳 |

### 3.5 제목 점검표 (모두 통과해야 채택)
- [ ] 메인 키워드가 정확히 1개 들어 있다
- [ ] 세부 키워드가 1개 이상 들어 있다
- [ ] 핵심 키워드가 앞쪽(약 27자 안)에 있다
- [ ] 같은 키워드를 두 번 쓰지 않았다
- [ ] 후킹 요소가 있다 (발견글은 필수)
- [ ] 키워드 나열이 아니라 읽히는 문장이다
- [ ] 본문이 제목의 약속을 지킨다
- [ ] 썸네일 문구와 같은 말이 아니다
- [ ] 글 목적(발견/문제해결/전환)과 공식(F1/F2)이 맞다

## 4. 썸네일 규칙

특강 노트는 썸네일이 가장 중요하다고 정리한다 [노트]. 피드에서 가장 먼저 보이는 요소라는 점에서 타당하지만, 클릭 후 본문이 약하면 이탈하므로 제목·본문과 함께 본다 [제안].

1. 이미지만 봐도 주제를 알 수 있어야 한다.
2. 주제와 무관한 예쁜 사진은 쓰지 않는다 [자료].
3. 결과물 화면(앱·대시보드·화면 녹화 캡처) + 짧은 문구(숫자 포함 권장) 템플릿을 기본으로 한다 [제안].
4. 모바일 피드 크기로 줄여서 글자가 읽히는지 확인한다 [자료].
5. 제목과 다른 정보를 준다. 제목의 궁금증을 증폭하는 방향 [자료].
6. 직접 만든 이미지만 쓴다. 타인의 이미지를 내려받아 재업로드하지 않는다.
7. 템플릿 1~2종을 고정해 블로그의 일관된 인상을 만든다.
8. 사진형과 스크린샷형을 번갈아 써서 반응을 기록한다 (A/B).

---

## 5. 본문 규칙

1. 도입부 3~5문장 안에 제목이 약속한 핵심을 먼저 보여준다.
2. **직접 경험 문단을 반드시 넣는다.** 해본 순서, 막힌 점, 결과를 쓴다.
3. 실제 화면·결과 이미지를 넣는다. 복사·붙여넣기와 유사 문서는 저품질 원인이다 [자료].
4. 소제목으로 구조를 나누고, 세부 키워드는 본문에 자연스럽게 녹인다.
5. 글 끝에 독자 질문 1개를 넣어 댓글을 유도한다 [제안].
6. 전환글에는 자사 상품·뉴스레터 등 CTA를 마지막에 한 번만 넣는다.
7. 쇼핑커넥트 링크를 쓸 때는 수수료를 상품별로 직접 확인하고, 광고임을 밝힌다. 본인·가족 구매는 실적으로 인정되지 않는다 [자료].
8. AI 초안은 초안일 뿐이다. 경험·수치·화면은 반드시 작성자가 직접 채운다.

## 6. 이웃·댓글

- 네이버가 공식 밝힌 추천 기준은 이웃 관계, 관심사, 활동 이력이다 [공식]. 이웃과 댓글은 이 기준에 가까운 요소다.
- 같은 주제를 쓰는 블로거와 실제로 읽고 구체적으로 댓글을 단다.
- 맞댓글 품앗이, 복사한 형식 댓글, 자동 댓글은 하지 않는다. 광고성 댓글이 블로그 신뢰를 떨어뜨렸다는 진단이 있다 [자료].

## 7. 클립 연계

- 블로그 글 하나당 클립 1편: 세로 9:16, 15~60초 기준 [자료].
- 클립 에디터의 **블로그 정보 스티커**로 해당 글을 연결한다 [공식].
- 활동 요건은 2차 자료 기준 월 동영상 10건 또는 게시물 15건이지만 회차마다 다르다. 모집·활동비·수익화 자격은 클립 크리에이터 앱과 공지에서 직접 확인한다 [자료].
- 업로드와 스티커 부착은 직접 한다. 공식 자동 업로드 API 지원 여부는 확인하지 못했다.

| 항목 | 내용 |
|---|---|

| 제목·썸네일 | 제목 버전, 썸네일 유형(사진/스크린샷) |

| 클립 | 연계 여부, 클립 조회수 |
| 메모 | 반응이 좋았던 점, 개선할 점 |

## 9. 금지 사항

- 메인 키워드 또는 세부 키워드가 없는 제목
- 키워드 나열형 제목, 같은 키워드를 반복하는 제목
- 본문과 맞지 않는 낚시성 제목·썸네일
- 복사·붙여넣기, 타인 이미지 재업로드
- 자동 댓글·이웃 추가·조회수 조작, 무인 대량 발행
- "홈판 노출 보장", "월 수익 보장" 같은 표현

```
- 메인:
- 세부(3개 이상):
- 서브:

## 3. 제목 후보 5개
각 후보마다: 제목 / 사용한 메인 키워드 / 사용한 세부 키워드 / 후킹 요소 / 점검표 결과

## 4. 추천 제목 1개와 이유

## 5. 썸네일 문구 후보 3개 + 이미지 구성 제안
(제목과 같은 말을 반복하지 않을 것)

도입부 핵심 / 소제목 / 작성자가 직접 채울 경험·화면·수치 목록 / 독자 질문 1개

```
