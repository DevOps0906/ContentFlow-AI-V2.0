# 디자인 시안 — ContentFlow AI

> 2026-11-06 기준 구현 화면의 캡처와 규칙이다. 토큰의 정본은 `apps/web/src/app/globals.css`의 `:root`, 요약은 [DESIGN.md](../../DESIGN.md).
> 캡처는 헤드리스 Chrome(로컬 컨테이너)이다. 빈 상태, 샘플 글 6개(브라우저 저장), 로그인·계정 모드, 키워드→글 흐름을 포함한다. 키보드 조작·저장 실패 화면은 아직 확인하지 않았다.

## 1. 방향과 토큰

| 항목 | 기준 |
|---|---|
| 방향 | 차분한 블로그 편집 스튜디오, 밝은 작업 공간과 민트 포인트 |
| 구성 | 고정 사이드바 · 상단 경로/검색 · 본문 카드 · 하단 안내 |
| 색상 | 배경 `--bg #f7f9fb`, 본문 `--ink #202c38`, 강조 `--green #239b82`, 선 `--line #e9edf1` |
| 보조색 | blue `#5285ca`, amber `#b58b35`, purple `#9376bf`, rose `#c7778e` (각 `-bg` 배경 쌍) |
| 반경/그림자 | `--radius 14px`, 카드 그림자 최소 |
| 글자 | 기본 14px(1200~), 13px(~1199) |
| 반응형 | 모바일 ~767 · 태블릿 768~1199 · 데스크톱 1200~ (3구간) |

## 2. 상태 표시 규칙

| 단계 그룹 | 포함 상태 | 배지 색 |
|---|---|---|
| 기획 | 아이디어, 자료 조사, 브리프 작성 | purple |
| 작성·검수 | 초안 작성, QA 대기, 수정 필요, 승인 대기 | 회색 |
| 승인·내보내기 | 승인 완료, 내보내기 준비 | mint |
| 게시 | 수동 게시 대기, 발행 중, 발행 실패, 초안 생성됨, 게시 완료 | blue |
| 사후 관리 | 성과 모니터링, 업데이트 필요 | amber |

수정 필요·발행 실패·업데이트 필요는 그룹 색 대신 rose 경고. 데이터가 없는 값(광고 수익 등)은 `—` 또는 N/A로 표시하고 0으로 채우지 않는다.

## 4. 편집기 구성

| 영역 | 내용 |
|---|---|
| 본문 영역 | 제목 · 템플릿/발행 대상 · 핵심 키워드 · 본문 탭(작성/미리보기, **AI 초안 생성**) · 근거 URL · 저장/검수 요청 |
| 오른쪽 패널 | 선택한 템플릿 블록·필수 근거 / **진행 상태**(현재 상태 배지, 5단계 진행 막대, 다음 단계 버튼) |
| AI 버튼 | 키 없음: "AI 미연결" 비활성. 본문이 이미 있으면 교체 확인 대화상자 |
| 다음 단계 버튼 | 승인(확인 체크 필요) → HTML 내보내기 → 수동 게시 시작 → 게시 완료 확인. WordPress 설정 시 "WordPress 초안 보내기". CMS 필요 상태는 비활성 + "CMS 연동 전" |

## 5. 접근성·안전 표시

- skip link, label 연결, focus 표시, 대화상자 focus trap, reduced motion.
- 미리보기는 React 텍스트 렌더링이며 원본 HTML·광고 script를 실행하지 않는다.
- 저장하지 않은 변경이 있으면 이탈 전에 확인한다. 저장소 오류 시 원본을 덮어쓰지 않는다.
- AI 초안은 "참고용"임을 본문 아래에 표시하고, `[확인 필요]` 표시가 남으면 검수를 차단한다.

## 6. 미완료 디자인 항목

- 오류 상태(저장소 읽기 실패, 저장 실패)와 게시 이후 단계(수동 게시 대기·게시 완료)의 편집기 캡처.
- 키보드만으로 전체 흐름 조작 확인.
- 워크스페이스 전환·팀 초대·권한별 화면, 비밀번호 재설정·이메일 확인 화면.
- 광고 배치 미리보기, 사이트 표시 프로필 화면([수익화 기획](../01-planning/MONETIZATION_STRATEGY.md) B02).
