# 오버레이 UX 적용표 (CF-20 · CF-21)

가이드: `ui-overlay-patterns`(토스트·스낵바·액션시트). 구현: `apps/web/src/components/feedback.tsx`(`FeedbackProvider`, `useFeedback`), `row-menu.tsx`(`RowMenu`), 상태 로직 `src/lib/feedback.ts`.

## 공통 규칙

| 항목 | 토스트 | 스낵바 |
|---|---|---|
| 용도 | 성공만 알림 | 결과 + 실행 취소 |
| 유지 시간 | 4초 | 8초 이상, 마우스 올림·키보드 포커스 중 멈춤. 포커스가 알림 안에 있으면 마우스가 떠나도 재개하지 않고, 둘 다 없어질 때 최소 1.5초 더 |
| 닫기 | 자동, Esc | 자동, `알림 닫기` 버튼, Esc |
| 실행 취소 키보드 | - | 표시 중 `Ctrl+Z`(Mac `Cmd+Z`)로 실행. 입력란·textarea·select·contenteditable에 포커스가 있으면 브라우저 기본 실행 취소를 우선. 버튼에 단축키 표시(모바일 제외). 포커스를 빼앗지 않음 |
| 동시 표시 | 1개. 새 알림이 이전 알림을 교체 | 동일 |
| 위치 | 모바일(~767) 하단 중앙(safe-area), 태블릿·데스크톱 하단 우측 | 동일 |
| 접근성 | 항상 렌더되는 `role=status aria-live=polite` 영역에는 메시지만 넣고, 버튼은 영역 밖. 화면에 보이는 문구는 `aria-hidden`(중복 낭독 방지) | 동일 |
| 토큰 | `--z-feedback`, `--motion-fast`, `--motion-ease`. reduced-motion이면 애니메이션 없음 | 동일 |

오류는 토스트로 보내지 않고 기존처럼 입력·작업 영역의 `role=alert` 인라인으로 남긴다. 검수·승인 안내, WordPress 전송 안내, CSV 가져오기 결과처럼 읽고 따라야 하는 긴 안내도 인라인 유지.

| 편집기 | 템플릿 적용 / 티스토리 패키지 내려받기 / 블로그 계정 변경 / 임시 저장 | 토스트 | 토스트 | 각 성공 문구 | 작업 영역은 그대로 |

## 키보드

- `⋯` 버튼: Enter·Space로 열기, 데스크톱에서는 위·아래 화살표로도 열기. 열리면 첫 항목에 포커스.
- 데스크톱 메뉴에서 Tab은 메뉴를 닫는다. 모바일 시트에서는 Tab이 시트 안에서만 돈다.
- 스낵바·토스트는 Tab으로 `실행 취소`·`알림 닫기`에 닿을 수 있고, 포커스가 있는 동안 사라지지 않는다.

## 계정 모드 / 로컬 모드 차이

| 작업 | 로컬 모드(브라우저 저장) | 계정 모드(DB) |
|---|---|---|
| 키워드 삭제 | 즉시 삭제 + 스낵바 실행 취소(Ctrl+Z) | **확인창(ConfirmDialog)** 후 삭제, 실행 취소 없음(API가 같은 ID·블로그 연결을 되살릴 수 없음) |
| 블로그 계정 보관 | 계정 관리는 계정 모드 전용 | 즉시 보관 + 스낵바 실행 취소(PATCH active) |
| 콘텐츠 삭제 | 확인창 | 확인창 |

## 메뉴 동작 보충

- 데스크톱 드롭다운: 아래 공간이 부족하면 트리거 위로 연다. 메뉴 안 포커스 이동으로 생긴 스크롤에는 닫히지 않고, 바깥 스크롤·창 크기 변경에서만 닫힌다. Tab은 트리거로 포커스를 돌려준 뒤 닫는다.
- 액션시트가 열려 있는 동안 시트가 토스트·스낵바 위에 놓인다(`--z-sheet` 95 > `--z-feedback` 90). 루트 viewport는 `viewportFit: cover`로 safe-area를 쓴다.

## CF-21 확대 적용

### 토스트 vs 인라인 판단 기준

| 구분 | 기준 | 처리 |
|---|---|---|
| 토스트 | 한 문장짜리 성공 확인. 다시 읽을 필요 없고 따라 할 일이 없음 | `useFeedback().toast` |
| 인라인 유지 | 오류·경고, 건너뜀·중복·제외 같은 결과 내역, 승인 상태·다음 행동 안내, 링크·이메일 미발송 같은 안내, 현재 상태 요약, 로딩 | `role=alert`(오류) 또는 `role=status` 영역 |
| 혼합 메시지 | 성공 + 부연(`notice`)이 함께 나오면 부연이 있는 쪽이 이김 → 통째로 인라인 | 부연 없는 순수 성공만 토스트 |

토스트로 바꾼 뒤 인라인에 남는 메시지는 오류·경고뿐이면 `role=alert`로 바꿨다.

### 화면별 표

| 화면 | 토스트로 이동 | 인라인 유지(이유) |
|---|---|---|
| 설정 > AI API | `이 브라우저에 저장했어요…`, `연결됨 · 사용 가능한 모델 N개` | 저장소 실패·연결 실패(오류) |
| 수익 분석 | 없음 | CSV·브라우저 가져오기 결과(건너뜀·중복·오류 행 내역), 삭제 실패 |
| 성과 기록(blog-metrics) | `저장했어요.`(부연 없을 때) | CSV 결과, 기존 값 유지 안내, 오류 |
| 제작 원가 | `기록했어요.` | 기록했지만 목록 새로고침 실패(재입력 방지 경고), 오류 |
| 개선 큐 | `개선 큐에 추가했어요.`, 행 `기록했어요.` | 오류 |
| 설정(일반) | `브라우저 원본 데이터를 백업했어요.`, `로컬 데이터를 초기화했어요.` | 계정 가져오기 결과(개수·재승인 안내), 오류 |
| 사이트 점검 | 행 `기록했어요.` | 기록 요약(현재 상태), 오류 |
| 팀 | 역할 변경·초대 거절·초대 취소·내보내기 | `님을 초대했어요…이메일은 발송되지 않아요`(다시 읽어야 하는 안내), 오류 |
| 제목 평가 | 없음 | `저장했어요. 승인 상태는 바뀌지 않습니다.`(승인 상태 안내) |
| 트렌드 | `저장했어요.`(부연 없을 때) | CSV 결과, 기존 값 유지 안내, 글 만들기 결과(편집기 링크), 오류 |
| 대시보드 모바일 앱 카드 | 없음 | `불러오는 중…`(로딩 상태) |
| 편집기·키워드·콘텐츠·블로그 계정 | CF-20 그대로 | CF-20 그대로 |

### 행 메뉴(`⋯`) 확대

| 화면 | 적용 | 메뉴 항목 | 적용하지 않은 곳과 이유 |
|---|---|---|---|
| 키워드 · 제목 랩 | 적용 | `제목 후보`, `삭제`(기존 로컬 스낵바 / 계정 ConfirmDialog 규칙 그대로) | 주 행동 `글 만들기`는 한 번에 닿도록 행에 남김 |
| 트렌드·성과 기록 | 미적용 | - | 행 작업이 삭제 아이콘 1개(+글 만들기). 항목 1개짜리 메뉴는 오히려 한 단계 늘어남. 삭제 아이콘에는 툴팁 |
| 제작 원가·개선 큐 | 미적용 | - | 행 작업이 1개이거나 폼 중심 |
| 블로그 계정·팀 | 미적용 | - | 텍스트 버튼 라벨(수정·보관)이 의미를 직접 설명하고 e2e 계약이 있음. 필요하면 다음 작업 |

### 툴팁 (`components/tooltip.tsx`)

| 항목 | 규칙 |
|---|---|
| `Tooltip` | 아이콘 버튼·비활성 버튼 이유 설명. 마우스 호버(마우스·펜만)와 **키보드 포커스**(`:focus-visible`)에서 표시, `Esc`로 닫기(열려 있을 때만 이벤트를 막아 바깥 다이얼로그·메뉴는 유지), `role=tooltip` + `aria-describedby`. 버튼 `aria-label`과 문구가 같으면 중복 낭독 방지로 describedby 생략 |
| 비활성 버튼 | 비활성 버튼은 포커스·호버가 없으므로 감싼 span이 `tabindex=0`으로 포커스를 받고 설명을 가짐 |
| `InfoTip` | 용어 설명용 정보 버튼. 호버·포커스에서 표시, **탭하면 토글**(터치), 바깥 탭·`Esc`로 닫기 |
| 위치 | `body`로 포털 + `position: fixed`: 표 스크롤 래퍼와 변형된 드로어에 잘리지 않음. 위쪽 공간이 없으면 아래, 가로는 화면 안으로 보정. 스크롤·리사이즈 시 닫힘 |
| `title` 정리 | 의미 있는 설명 → Tooltip/InfoTip, aria-label과 같은 중복 `title` 제거 |

| 위치 | 이전 | 이후 |
|---|---|---|
| 사이드바 로그아웃 | `title` 중복 | Tooltip `로그아웃` |
| 트렌드·성과 기록 삭제 아이콘 | `title="삭제"` | Tooltip `삭제` |
| 트렌드 기회 점수 | 셀 `title`(없는 값) | InfoTip(탭·포커스 가능) |
| 편집기 AI 초안·AI 교차 검수 | 비활성 사유 `title` | Tooltip |
| 편집기 수동 전환 버튼(비활성) | `title` | Tooltip |

### 모바일 메뉴 드로어 (`shell.tsx`, 767px 이하)

| 검수 항목 | 구현 |
|---|---|
| 열 때 포커스 이동 | 드로어 안 `닫기` 버튼으로 이동 |
| 포커스 가둠 | `Tab`/`Shift+Tab`이 드로어 안에서만 순환(`wrapFocusIndex`). 배경(`main-wrap`)은 `inert`, 드로어는 `role=dialog aria-modal` |
| 닫기 | `Esc`, 배경 탭, 드로어 안 `닫기` 버튼, 상단 토글. 링크를 눌러 이동하면 본문으로 포커스 |
| 닫은 뒤 | `Esc`·배경·닫기 버튼은 메뉴 버튼으로 포커스 복귀 |
| 배경 스크롤 | 열려 있는 동안 `body` 스크롤 잠금(닫으면 원래 값 복원) |
| 닫힌 상태 | 화면 밖 사이드바는 `inert`: Tab·스크린리더에서 제외 |
| 폭 변경 | 768px 이상으로 넓어지면 자동으로 닫힘(고정 사이드바) |
| 토글 버튼 | `aria-expanded`, `aria-controls` |
