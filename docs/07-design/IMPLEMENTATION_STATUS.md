## 5. 다음 순서 제안

1. **로그인·권한**: Supabase Auth + 워크스페이스 멤버십. API가 DB의 글 상태를 기준으로 검증하도록 전환.
2. **앱 데이터 DB 저장**: 브라우저 저장소 → `articles/article_versions/approvals`, 승인 스냅샷 해시.
3. **키워드→글 연결**: 아이디어 단계 생성, 키워드 상태 연동.
4. **QA 게이트**: 규칙 기반 + (선택) 두 번째 모델 검수, 출처 확인 기록.
5. **측정**: 보고서 CSV 가져오기, 원가 장부, N/A 규칙 유지.
6. 시각 검증(저장된 글·키보드·오류 화면) 병행.
