## 5. 다음 순서 제안

1. **QA 게이트**: 규칙 기반 + (선택) 두 번째 모델 검수, 출처 확인 기록. 실제 OpenAI 키로 AI 초안 검증. 기획 단계(자료 조사·브리프)에 입력 항목(출처·브리프 메모) 추가.
2. **키워드의 DB 저장**: 계정 모드에서 키워드도 기기 간 동기화, 키워드↔글을 문구 일치 대신 ID로 연결.
3. **팀 기능**: 초대, 역할 변경 화면, 검수자(reviewer) 승인 흐름.
4. **측정**: 보고서 CSV 가져오기, 원가 장부, N/A 규칙 유지.
5. **운영 준비**: 클라우드 Supabase 프로젝트, https·`COOKIE_SECURE`, 이메일 확인·비밀번호 재설정, 로그인 시도 제한의 공유 저장소(현재는 프로세스 메모리).
6. 시각 검증(키보드·오류 화면) 병행.
