## (1) API 상품 정보(상품명·가격)를 AI 프롬프트에 넣어 초안 생성 → 조건부(회색, 서면 확인 권장)
- [원문확인] Open API 약관 제5조 3항: API로 받은 데이터를 "복제, 저장 또는 전송할 수 없습니다". 접근만 허용한다.
  → 외부 LLM 제공사로 보내는 것은 문언상 "전송"에 해당할 여지가 있고, DB에 캐시하면 "저장"에 해당한다.
- [원문확인] Open API 약관 제5조 2항: 데이터 저작권은 회사 또는 제3자에게 있다. 승인받았다고 데이터 이용권이 생기지 않는다.
- [원문확인] Open API 약관 제6조: "회사가 제공한 정보 변경" 금지. 이용약관 제8조 2항: 광고의 내용·링크·순서와 그에 포함된 정보를 변경·조작하는 행위 금지.
  운영정책 4.1 1)도 광고에 포함된 정보의 조작을 금지한다(A등급: 1회 위반 시 14일 수익 몰수, 2회 위반 시 계정 해지).
- [원문확인] 이용약관 제8조: 사실과 다르거나 과장된 내용 게시 금지(표시광고법).
- [미확인] AI 프롬프트 입력을 명시적으로 허용하거나 금지하는 조항은 없다.
- 제품 변경: 가격·상품명은 AI가 쓰지 않게 하고, 표시 시점에 API 값을 그대로 렌더링한다(플레이스홀더). 원문 데이터는 캐시하지 않고 조회 시각을 표기한다.
  LLM에는 사용자가 직접 입력한 특징·카테고리 수준만 넣는다. 정식 출시 전 partners@coupang.com에 서면 확인을 받는다.

## (2) 키 하나를 여러 고객(SaaS)이 공유 → 금지
- [원문확인] 운영정책 4.1 5): API Key를 포함한 권한을 "회사의 서면 동의 없이" 타인에게 공유·제공·양도·중개·재판매하는 행위 금지(B등급 위반).
- [원문확인] Open API 약관 제4조 1·2항: 이용자당 인증키 1개만 쓸 수 있고, 키를 제3자에게 제공·공개·공유·대여·양도할 수 없다.
- [원문확인] 이용약관 제8조: 회원 계정의 공유·제공·중개·재판매 금지. 등록되지 않은 미디어로 참여하는 행위도 금지한다.
- [미확인/위험] 고객이 자기 키를 SaaS에 맡기는 BYOK도 제4조 2항의 "제3자 제공"으로 볼 여지가 있다. 운영정책의 "서면 동의" 예외로 허락받는 것이 정답이다.
- [자료] 사이트 번들에 `/api/v1/agency/children/bind` 엔드포인트가 있다. 대행사 계정 연결 제도가 있는 것으로 보이지만 공개 설명은 미확인이다.
- 제품 변경: 운영자 공용 키를 쓰지 않는다. 기본은 고객이 자기 계정에서 링크를 만들어 붙여넣는 방식이다. BYOK는 쿠팡 서면 동의나 대행사(agency) 경로를 확인한 뒤에만 켠다.

## (3) 호출 제한(공식 수치)
- [원문확인] 문서 탭 `/products/search`: 1분당 최대 50번 호출. `/reports/*`: 1시간당 최대 500번 호출.
- [원문확인] FAQ: 일부 API에 시간당 횟수 제한이 있고, 한도에 도달하면 "24시간 동안" 사용이 제한된다. 일별 제한은 없지만 비정상적인 과도한 호출은 제한 대상이다.
- [원문확인] Open API 약관 제3조: 회사는 별도의 시간대·횟수를 지정할 수 있다. 과부하를 일으키면 제한·정지할 수 있다.
- [미확인] goldbox·bestcategories·coupangPL·reco·deeplink의 개별 수치는 열람하지 못했다.
- 제품 변경: 키별로 search 50/분 토큰버킷과 서버 캐시 없는 순차 큐를 둔다. 24시간 차단을 감지하면 UI에 "N/A"를 표시한다.

## (4) 대가 문구 의무 → 필수
- [원문확인] 이용약관 제12조 4항: 공정위 「추천·보증 등에 관한 표시·광고 심사지침」에 따라 경제적 이해관계를 공개해야 한다.
- [원문확인] FAQ: 파트너스 활동으로 게재한 "모든 게시물"에 표시해야 한다. 위치는 제목 또는 첫 부분이다.
  첫 부분에 넣으면 글자를 본문보다 크게 하거나 색을 달리한다. '더보기' 뒤에 두거나, 본문 중간에 넣거나, 링크와 분리하거나, 별도 페이지로 보내는 것은 부적절하다.
- [원문확인] 권장 문구(FAQ): "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
  사이트 링크 생성 화면은 "이 포스팅은 …"으로 표기한다(문구 차이는 허용 범위로 보인다).
- [원문확인] FAQ(AI): AI 가상인물이 추천하면 '가상인물' 표시가 필수다. 체험 후기처럼 쓴 내용이 실제 경험과 다르면 부당 광고에 해당할 수 있다.
- 제품 변경: 기존 고지 게이트(0028)가 고지 문구를 본문 첫 블록·강조 스타일로 강제하는지 확인한다. AI 체험담("써보니") 생성을 차단하고, 가상인물 경고를 추가한다.

## (5) 블로그 글 자동 생성·게시 → 조건부(AI 생성은 허용 전제, 자동 게시 조항 없음)
- [원문확인] FAQ에 "AI로 생성한 컨텐츠를 활용하는 경우" 항목이 있다. AI 콘텐츠 자체를 금지하지 않고 표시 의무만 둔다.
- [원문확인] 운영정책 4.1 7): 고유 콘텐츠보다 광고성 콘텐츠 비중이 "압도적으로 큰 경우" 이용을 제한한다.
  6) 기타: 특정 문구 반복이나 도배성 게시물은 부적합 콘텐츠다. 3): 무의미한 키워드 삽입은 A등급 위반이다.
- [원문확인] 이용약관 제8조: 로봇·스파이더·스크레이퍼 등 자동화 수단으로 서비스에 접근하는 행위 금지. 상품 정보는 API로만 받는다.
- [원문확인] 운영정책 4.1 1): 등록되지 않은 미디어에 광고를 노출하는 행위 금지. 게시 대상 블로그마다 해당 고객 계정에 미디어 등록이 필요하다.
- [미확인] 무인 자동 "게시" 자체를 금지하는 문구는 찾지 못했다.
- 제품 변경: 사람 승인 뒤 게시(현행 승인 게이트 유지), 일 발행량 상한, 고유 콘텐츠 비율 경고(C6 저품질 경고와 연결), 미디어 등록 확인 체크를 둔다.
