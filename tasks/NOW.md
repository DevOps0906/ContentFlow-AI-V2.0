# 현재 상태

| 항목 | 상태 |
|---|---|
| 단계 | QA 패널·키워드 DB·수익 CSV (CF-16~18), 키워드→아이디어 글 연결 (CF-15), 로그인·DB 저장·DB 상태 규칙 (CF-14), Docker·AI·WordPress (CF-11~13) |
| 주 모델 구성 | gpt-6.1-sol · 새 세션에 적용 |
| 부 모델 구성 | 루나-6.1 정확한 ID 확인 대기, agents.enabled=false |
| 하위 에이전트 실제 실행 | 없음 — 요청 모델 임의 대체 안 함 |
| UI | 개요/콘텐츠/키워드·제목 랩/템플릿/수익분석/설정 |
| 동작 | 저장/검색/5단계 그룹 필터/템플릿 전환/검수 요청(자동 판정)/승인/HTML·JSON export/수동 게시 확인 |
| 검증 | 타입·테스트 65개·빌드·Docker 이미지; 키워드→글 e2e 28(계정)/25(로컬), 키워드 API e2e 17, 수익 e2e 17; DB 규칙 테스트; 로그인 e2e 37·WordPress e2e 16; 의존성 감사 high 이상 0 |
| 브라우저 | 헤드리스 Chrome 스크린샷으로 데스크톱·태블릿·모바일(500px) 작성/목록 화면 확인. 글이 저장된 상태·키보드·저장 실패는 미확인 |
| DB | 코어 마이그레이션 0001 + RLS 테스트 통과(로컬 Docker Postgres). 라이브 DB 미적용 |
| 제한 | 이메일 확인·비밀번호 재설정·팀 초대·역할 화면 없음, 광고·스킨 없음, 실제 OpenAI 키 호출 미검증, 클라우드 Supabase 없음(로컬 스택) |
| 운영 | 로컬 Supabase 실행 중(포트 60321~, `npx supabase stop`으로 중지). 웹 컨테이너 기본 포트 3410 |
| 로직 | 16단계 상태 전이 UI 연결. 저장 키 v2, v1은 읽기 시 변환·보존(초기화 시 함께 삭제). CMS 필요 3개 상태는 비활성. 키워드→글(아이디어 단계) 연결은 미구현 |
| 후속 | 키워드의 DB 저장, 실제 OpenAI 키 검증, 수익 보고서 CSV, 팀 초대·역할, 모델 확인, 키보드·오류 화면 검증 |
| 문서 | 디자인 시안·개발 단계·완성도: docs/07-design/ |
| 전달 | 사용자 요청에 따라 각 저장소 커밋·푸시, README 표 갱신 |
