# 현재 상태

| 항목 | 상태 |
|---|---|
| 단계 | 팀·권한·인증 복구·수익 DB·AI 검수 의견, QA 패널·키워드 DB·수익 CSV (CF-16~18), 키워드→아이디어 글 연결 (CF-15), 로그인·DB 저장·DB 상태 규칙 (CF-14), Docker·AI·WordPress (CF-11~13) |
| 주 모델 구성 | gpt-6.1-sol · 새 세션에 적용 |
| 부 모델 구성 | 루나-6.1 정확한 ID 확인 대기, agents.enabled=false |
| 하위 에이전트 실제 실행 | 없음 — 요청 모델 임의 대체 안 함 |
| UI | 개요/콘텐츠/키워드·제목 랩/템플릿/수익분석/설정 |
| 동작 | 저장/검색/5단계 그룹 필터/템플릿 전환/검수 요청(자동 판정)/승인/HTML·JSON export/수동 게시 확인 |
| 검증 | 현재 타입·테스트 83개·production build·DB 규칙 테스트(0001~0006) 통과. 이전 검증: Docker 이미지; 키워드→글 e2e 28(계정)/25(로컬), 키워드 API e2e 17, 수익 e2e 17; DB 규칙 테스트; 로그인 e2e 37·WordPress e2e 16; 의존성 감사 high 이상 0 |
| 브라우저 | 헤드리스 Chrome 스크린샷으로 데스크톱·태블릿·모바일(500px) 작성/목록 화면 확인. 글이 저장된 상태·키보드·저장 실패는 미확인 |
| DB | 0001~0006: 코어·상태 규칙·키워드·팀/역할·수익/ID 연결·공유 호출 제한. 이번 변경의 운영 DB 적용은 별도 필요 |
| 제한 | 팀 초대 메일 미발송, 새 팀·인증 복구·수익 DB·AI 검수의 브라우저 흐름과 운영 메일 미검증, 광고·스킨 없음, 실제 OpenAI 키 호출 미검증, 클라우드 Supabase 없음(로컬 스택) |
| 운영 | 로컬 Supabase 실행 중(포트 60321~, `npx supabase stop`으로 중지). 웹 컨테이너 기본 포트 3410 |
| 로직 | 16단계 상태 전이 UI 연결. 저장 키 v2, v1은 읽기 시 변환·보존(초기화 시 함께 삭제). CMS 필요 3개 상태는 비활성. 키워드→아이디어 글은 ID 연결, ID 없는 기존 글만 문구로 연결 |
| 후속 | 실제 OpenAI 초안·검수 호출, 운영 메일·비밀번호 복구, 팀·권한·워크스페이스 전환 브라우저 검증, 모델 확인, 키보드·오류 화면 검증 |
| 문서 | 디자인 시안·개발 단계·완성도: docs/07-design/ |
| 전달 | 사용자 요청에 따라 각 저장소 커밋·푸시, README 표 갱신 |

## 이번 추가 사항 (2026-11-06)

- 설정: 팀 초대·수락·취소·거절, 역할 관리·멤버 제거·탈퇴, 워크스페이스 전환. 초대 메일은 발송하지 않는다.
- 인증: 가입 확인 콜백, 비밀번호 복구 메일 요청·변경, `APP_URL` 설정. 운영 메일 검증은 후속이다.
- 데이터: 수익 보고서 계정 DB 저장·브라우저 자료 가져오기, 키워드↔글 ID 연결, 1,000행 초과 조회 페이지 처리.
- AI: `QA_MODEL` 검수 의견, 동일 작성 모델 표시, 자동 승인·상태 변경 없음.
- 호출 제한: DB 공유 제한, DB 오류 시 프로세스 메모리 제한으로 대체.
