# 현재 상태

| 항목 | 상태 |
|---|---|
| 단계 | 로컬 대시보드 및 NOMAD Codex 팀 도구 추가 |
| 주 모델 구성 | gpt-6.1-sol · 새 세션에 적용 |
| 부 모델 구성 | 루나-6.1 정확한 ID 확인 대기, agents.enabled=false |
| 하위 에이전트 실제 실행 | 없음 — 요청 모델 임의 대체 안 함 |
| UI | 개요/콘텐츠/키워드·제목 랩/템플릿/수익분석/설정 |
| 동작 | 저장/검색/분류/템플릿 전환/수동 검수/승인/HTML·JSON export |
| 검증 | 타입·프런트엔드 테스트 18개·빌드 통과; 의존성 감사 high 이상 0 |
| 브라우저 | HTTP 200; 앱 접근 승인 시간 초과로 시각 검증 미완료 |
| DB | 코어 마이그레이션 0001 + RLS 테스트 통과(로컬 Docker Postgres). 라이브 DB 미적용 |
| 제한 | 서버 인증/API/앱-DB 연동/실제 스킨·광고 적용 없음 |
| 로직 | 16단계 상태 전이(lifecycle.ts)·키워드 CSV·제목 후보 — UI는 키워드 화면만 연결, 글 상태는 3단계 유지 |
| 후속 | Supabase 프로젝트 확인 후 인증·앱 연동(CF-07b), 모델 확인, 시각 검증 |
| 전달 | 사용자 요청에 따라 각 저장소 커밋·푸시, README 표 갱신 |
